# BiciStore — Tienda de Bicicletas

Plataforma web de venta de bicicletas, repuestos, cascos y accesorios con catálogo interactivo.

## Características

- Catálogo de 24 productos con precios en pesos colombianos
- Filtro por categorías: Bicicletas, Repuestos, Cascos, Accesorios
- Buscador de productos en tiempo real
- Ordenamiento por precio y nombre
- Carrito de compras con:
  - Agregar y eliminar productos
  - Modificar cantidades (+/-)
  - Total automático
- Etiquetas de descuento en productos con oferta
- Indicador de stock bajo
- Formulario de contacto
- Menú responsivo para móvil
- Modo oscuro automático
- Diseño moderno y profesional

## Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, Variables CSS, Dark Mode)
- JavaScript (Vanilla)
- Google Fonts (Montserrat + Open Sans)

## Uso

Abrir `index.html` en cualquier navegador. No necesita servidor ni instalación.

## Estructura

